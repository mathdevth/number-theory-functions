ฟังก์ชันในทฤษฎีจำนวน

สื่อประกอบการติว สอวน. คณิตศาสตร์ ค่าย 1 สำหรับนักเรียน เรียนรู้และทบทวน φ(n), τ(n), σ(n) และ μ(n) ทีละขั้น ตั้งแต่เห็นภาพ ฝึกคำนวณ ไปจนถึงพิสูจน์

โทนสี:

เริ่มตรงไหนดี

เดินตามเส้นทางนี้จากบนลงล่าง แต่ละขั้นใช้ความรู้จากขั้นก่อนหน้า กดปุ่มเพื่อไปหน้านั้นได้เลย และกลับมาหน้านี้ได้จากแท็บ “เริ่มต้น”

ก่อนเริ่ม รู้ความหมายของ ตัวหาร, ห.ร.ม. และ จำนวนเฉพาะสัมพัทธ์ แล้วหรือยัง

จุดที่ควรทบทวน

แอปจดผลจากเกมศึกชิงค่าฟังก์ชัน เกมเก็บจำนวนเฉพาะสัมพัทธ์ และการเติมตาราง แยกตามฟังก์ชัน ข้อมูลเก็บไว้ในเครื่องนี้เท่านั้น

ทางลัด

เลือกจำนวนเต็มบวก n

ทุกฟังก์ชันเริ่มจากขั้นเดียวกัน คือ เขียน n ในรูปผลคูณของกำลังของจำนวนเฉพาะ

f(mn) = f(m)·f(n) จริงเมื่อไร

ฟังก์ชันการคูณ คือฟังก์ชันที่ f(mn) = f(m)f(n) ทุกครั้งที่ (m, n) = 1 ลองเลือก m, n ทั้งแบบที่เป็นจำนวนเฉพาะสัมพัทธ์และแบบที่ไม่เป็น แล้วสังเกตตาราง

เติมตารางค่าฟังก์ชัน n = 1 ถึง 12

ตารางเดียวกับในเอกสารประกอบการเรียน ช่องจะเปลี่ยนเป็นสีเขียวเมื่อถูก สีแดงเมื่อยังไม่ถูก ถ้าติดให้กลับไปดูหน้า “สำรวจทีละฟังก์ชัน”

ฝึกพิสูจน์

ทุกข้อเดินตามลำดับเดียวกัน คือ ทดลองกับตัวเลขจนเชื่อ จับแนวคิดหลัก แล้วจึงเขียนบทพิสูจน์ทีละขั้น จะเปิดอ่านทีละขั้น หรือลองเรียงลำดับขั้นเองก็ได้

โจทย์ท้ายบทจากเอกสาร

โจทย์ 1 ถึง 32 โจทย์พิเศษข้อ 33 และแบบฝึกหัดจากเอกสารประกอบการเรียน เลขข้อตรงกับในเอกสาร ลองทำเองก่อน ติดแล้วค่อยเปิดคำใบ้ และเปิดเฉลยเป็นลำดับสุดท้าย

พิมพ์ตามหมวดที่เลือกอยู่

โจทย์ย้อนกลับ: รู้ค่าฟังก์ชัน หา n ทั้งหมด

โจทย์แนวนี้พลาดง่ายเพราะตกหล่นคำตอบ หลักคือจำกัดตัวเลือกให้เหลือน้อยที่สุดก่อน แล้วไล่กรณีอย่างเป็นระบบ เลือกฟังก์ชันและค่าที่ต้องการ แล้วลองทำเองก่อนเปิดดูขั้นตอน

สรุปสูตร

ให้ n = p₁a₁p₂a₂…pkak เป็นรูปแยกตัวประกอบของ n ทั้งสี่ฟังก์ชันเป็นฟังก์ชันการคูณ

กราฟค่าฟังก์ชัน n = 1 ถึง 200

ตารางค่า n = 1 ถึง 30

ทฤษฎีบทออยเลอร์

ถ้า (a, n) = 1 แล้ว aφ(n) ≡ 1 (mod n) ลองเปลี่ยน a และ n แล้วดูเศษของ a, a², a³, … เมื่อหารด้วย n

สูตรผกผันเมอบิอุส

จาก Σd|n φ(d) = n สูตรผกผันเมอบิอุสให้ผลกลับด้านว่า φ(n) = Σd|n μ(d)·(n ÷ d) ลองตรวจกับค่า n ต่าง ๆ

จำนวนสมบูรณ์กับจำนวนเฉพาะแมร์แซน

ถ้า 2p − 1 เป็นจำนวนเฉพาะ (เรียกว่าจำนวนเฉพาะแมร์แซน) แล้ว n = 2p−1(2p − 1) เป็นจำนวนสมบูรณ์ เพราะ σ(n) = σ(2p−1)·σ(2p − 1) = (2p − 1)·2p = 2n
